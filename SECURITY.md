# Security Policy

## Supported Versions

Security fixes are provided for the latest published release. Older major versions
receive fixes only when maintainers judge that an issue affects a widely used
release.

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues or pull requests.
Use GitHub's private vulnerability reporting form for this repository:

https://github.com/hella-labs/wiremock-testcontainers-nodejs/security/advisories/new

Include:

- A description of the vulnerability and its impact
- Affected versions or commit ranges
- Reproduction steps or a minimal proof of concept
- Suggested remediation, if available
- Your preferred contact and disclosure details

You will receive an acknowledgement within 5 business days. After triage, we
will share an expected response and remediation timeline where practical.
Coordinated disclosure will be agreed before any public announcement.

## Scope

This policy applies to the library and its maintained examples and documentation.
The WireMock, Testcontainers, Docker, and Java runtimes used by this project are
maintained by upstream projects.
