# Support

For usage questions and general help:

- Read the [documentation](https://hellalabs.dev/wiremock-testcontainers-nodejs/)
- Check the [troubleshooting guide](https://hellalabs.dev/wiremock-testcontainers-nodejs/docs/reference/troubleshooting)
- Review existing [GitHub issues](https://github.com/hella-labs/wiremock-testcontainers-nodejs/issues)

For bugs or reproducible failures, open a bug report. For ideas or API proposals,
open a feature request. If you are unsure which category applies, open a question
in the issue tracker.

Before reporting a problem, include:

- Library and Node.js versions
- Operating system and architecture
- Container runtime and version
- Relevant configuration and the smallest reproducible example
- Complete error output and relevant logs

Do not use public issues to report security vulnerabilities. Follow the
[security policy](./SECURITY.md).
